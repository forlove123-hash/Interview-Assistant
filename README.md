# Interview Assistant

> 基于 Dify 的智能模拟面试与求职评估系统

**当前状态：需求设计阶段。** 仓库目前只包含需求文档，尚未提供可运行的应用代码；请勿把本文档中的技术选型理解为已经实现的功能。

## 项目简介

Interview Assistant 面向正在准备求职面试的学生和初级从业者。用户上传简历、录入目标岗位 JD 后，系统生成个性化面试蓝图，通过多轮文本对话完成一场有计时、有追问、可中断恢复的模拟面试，并在结束后给出逐题反馈、五维能力评估和 7 天改进计划。

项目的重点不是“接一个大模型接口”，而是把**个性化上下文、可控的面试状态机、可解释的评分规则和可执行的改进建议**串成完整闭环。

## 核心能力（P0）

- **简历与岗位**：PDF/DOCX 简历解析、人工校对、主简历管理；JD 结构化提取；简历-JD 参考匹配度。
- **个性化面试**：根据简历、JD、面试类型、难度和时长生成面试蓝图，围绕候选人经历自适应追问。
- **可控的面试过程**：服务端计时、单题提交、跳过限制、断线恢复、幂等开始、降级题库。
- **异步评估**：回答入库后由后台任务逐题评估，不阻塞候选人继续作答。
- **综合报告**：五维雷达、逐题证据与改进建议、7 天行动计划、完成度与置信度提示。
- **数据与隐私**：资源归属校验、简历去敏、默认不录音、记录可删除、账号注销冷静期。
- **基础运维**：健康检查、结构化日志、请求追踪、失败任务重试、数据保留清理。

P1/P2 再考虑语音输入与 TTS、PDF 导出、管理后台、邮件通知、趋势分析、视频录制/回放（不做情绪、人格或颜值判断）等能力。

## 产品边界

本系统是**面试练习与求职评估工具**，不是企业招聘系统，也不会：

- 预测录用概率或替代真实面试；
- 根据视频、表情、眼神、语气做情绪或人格判断；
- 自动把候选人推荐给企业；
- 把 AI 评分包装成对候选人能力的最终结论。

报告中的分数只反映本次练习表现，必须与免责声明一起展示。

## 建议技术栈

| 层次 | 建议选型 | 说明 |
|---|---|---|
| 前端 | Vue 3 + TypeScript + Vite + Pinia + ECharts | 网页端；接口设计不绑定具体前端框架 |
| 后端 | Python 3.11+、FastAPI、Pydantic v2 | 业务状态与评分的唯一事实来源 |
| 数据 | PostgreSQL 15+、SQLAlchemy 2、Alembic | 关系数据、迁移与审计 |
| 异步 | Redis 7+、Celery 5 | 解析、评估、报告、清理任务 |
| 文件 | MinIO / S3 兼容对象存储 | 私有桶、预签名上传、服务端加密 |
| AI 编排 | Dify（4 个应用）+ 可选知识库 | 后端调用，浏览器不持有 Dify Key |
| 部署 | Docker Compose | 开发与演示环境优先 |

Dify 侧建议拆分为四个职责单一的应用：

- `interview-conductor`：出题与追问；
- `answer-evaluator`：逐题结构化评估；
- `report-composer`：报告叙事与改进计划；
- `resume-jd-matcher`：简历与 JD 匹配。

## 架构原则

```text
浏览器（Vue）
   │  HTTPS / JSON / SSE
   ▼
FastAPI 业务服务
   ├── PostgreSQL：用户、简历、JD、会话、评分、报告
   ├── Redis / Celery：异步任务、限流、短期状态
   ├── 对象存储：简历原文件、导出文件
   └── Dify API：出题、评估、报告、匹配
             │
             ▼
        LLM / 知识库
```

1. **Python 掌握业务真相**：会话状态、题目顺序、分数聚合和报告状态由后端决定。
2. **Dify 只做生成与编排**：Dify 返回结构化结果，不直接决定最终总分。
3. **浏览器不直连 Dify**：API Key 只存在于后端环境变量或密钥服务。
4. **评分可解释**：固定 rubric + 证据引用 + 确定性聚合，模型自报的汇总分不作为最终分。
5. **失败可降级**：Dify 超时或输出非法时，使用基础题库、模板报告或明确失败状态，不伪造结果。

## P0 验收主线

> 用户上传简历和 JD 后，能在 30 分钟内完成一场有追问的文本模拟面试，并在结束后获得一份有证据、有分数解释、有下一步行动、可删除的评估报告。

目标是在结束后 180 秒内生成报告（通常 90 秒内）；若样本不足，系统只给定性复盘，不展示数值总分。
